# Calculadora IPv4 e Subnetting v1.0.0

Ferramenta em português para calcular redes IPv4 e aprender subnetting.

- Interface web responsiva com PWA instalável pelo navegador e cache offline.
- Terminal Python e executável Windows x64.
- Validação de octetos e CIDR, sem zeros à esquerda.
- Rede, máscara, wildcard, broadcast, hosts, bloco e classificação.
- Tratamento de `/0`, `/31` e `/32`.
- Modo didático, cópia, exportação e histórico local.
- Testes comparativos com a biblioteca `ipaddress` do Python.

No Windows, baixe `CalculadoraIPv4.exe` e execute. O programa abre no terminal e dispensa instalar Python. O binário não possui assinatura de editor. `SHA256.txt` permite conferir o arquivo baixado.

No Android, use a interface web e a opção de instalação do navegador. Esta release não contém APK nativo.
